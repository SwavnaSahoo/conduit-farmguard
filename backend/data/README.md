# Data folder

`sample_conduit.csv` is synthetic demo data so the application runs before you have authenticated Conduit data.

Before judging, export the actual JKUAT Conduit dataset available to your hackathon account, place it here, and set `DATA_MODE=csv` plus `CONDUIT_CSV_PATH=./data/<your-file>.csv` in `backend/.env`.

Do not present the bundled sample file as measured JKUAT data.
